# 교사도우미 잠금화면 위젯 설계서

갤럭시 탭 S9+ (One UI 8.5, Android 16) 잠금화면에 오늘 시간표·일정·업무를 보여 주는 안드로이드 위젯 앱의 설계.
이 문서는 집 PC(Android Studio가 있는 PC)의 세션에서 위젯 앱을 만들 때 그대로 따라갈 수 있도록 쓴 것이다.

- 웹앱 쪽(요약 생성·동기화·교시 시간 설정)은 **이미 구현·배포됨**. 이 문서의 대상은 안드로이드 위젯 앱이다.
- 비밀 값(동기화 주소의 `key`)은 이 문서에 쓰지 않는다. 앱 설정 화면에서 사용자가 직접 입력한다.

## 1. 목표와 범위

| 항목 | 내용 |
|---|---|
| 목표 | 탭을 켰을 때(잠금 상태 포함) 오늘 시간표, 오늘 일정, 업무를 한눈에 본다. **단, 잠금화면 노출은 Good Lock(LockStar 모듈)이 켜져 있어야 함** — 이 기기 One UI 8.5의 기본 잠금화면 위젯 목록은 삼성·구글 1st-party 앱으로 고정되어 있고, LockStar를 켜면 모든 홈 화면 위젯(3rd-party 포함)을 잠금화면에 추가할 수 있다(0단계에서 확인) |
| 위젯 | **3종 독립 위젯(카드)**: 오늘 시간표 / 오늘 일정 / 업무 |
| 입력 | 읽기 전용. 위젯에서 데이터를 고치지 않는다 |
| 데이터 출처 | 교사도우미(PWA)가 구글 드라이브에 올린 `dashboardSummary` |
| 범위 밖 | 학생 정보·출결·행동특성 표시, 구글 캘린더 쓰기, 학교 일정 시트 표시 |

## 2. 전체 구조

```
교사도우미(PWA, 탭/PC)
   └ 데이터 변경 → 몇 초 뒤 자동 동기화(pushNow)
        └ 백업 JSON + dashboardSummary 를 Apps Script(doPost)로 업로드
             └ 구글 드라이브 teacher-app-sync.json
                  └ Apps Script doGet ?part=summary 가 dashboardSummary 만 반환
                       └ 위젯 앱(WorkManager)이 주기적으로 가져와 로컬에 저장
                            └ 위젯 3종이 저장된 요약을 그린다
```

- 위젯 앱은 **학생 데이터가 들어 있는 백업 전체를 절대 받지 않는다**. 반드시 `part=summary`만 호출한다.
- 위젯 앱은 구글 로그인을 하지 않는다. 동기화 주소(`.../exec?key=...`) 하나만 안다.

## 3. 데이터 계약

### 3.1 가져오기
```
GET {동기화주소}&part=summary&t={밀리초타임스탬프}
```
- `동기화주소`는 `https://script.google.com/macros/s/(배포ID)/exec?key=(키)` 형태. 이미 `?`가 있으므로 `&`로 이어 붙인다.
- Apps Script는 302로 리다이렉트한다. HTTP 클라이언트는 리다이렉트를 따라가야 한다(OkHttp 기본값 OK).
- `t`는 캐시 방지용.
- 정상 응답은 아래 요약 JSON 객체 자체(최상위가 `version: 1`).
- 비정상 응답:
  - `{"status":"error","message":"권한이 없습니다."}` → 키가 틀림. 설정 화면에 안내.
  - `{"empty":true}` → 아직 요약이 한 번도 올라오지 않음. "교사도우미를 열어 동기화해 주세요" 안내.
  - 그 밖(HTML 등) → 주소 오류. 마지막 성공 데이터를 유지하고 오류 표시.

### 3.2 요약 JSON 스키마 (`version: 1`)
웹앱의 `src/lib/dashboardSummary.ts`가 만든다. **값이 없는 선택 필드는 키 자체가 없다**(JSON에서 생략됨).

```ts
DashboardSummary {
  version: 1
  generatedAt: string          // ISO 시각. 요약을 만든 시각
  days: SummaryDay[]           // 생성일부터 14일, 날짜 오름차순
  overdueTasks: SummaryTask[]  // 생성일 기준 마감이 지났고 안 끝난 업무(최대 10, 오래된 순)
}
SummaryDay {
  date: string                 // "YYYY-MM-DD"
  weekday: number              // 0=일 … 6=토
  periods: SummaryPeriod[]     // 월~금만 채워짐. 수업 없는 교시는 목록에 없음
  events: SummaryEvent[]       // 그날 걸친 행사·개인 일정. 이미 시간순(시간 없는 건 뒤)
  tasks: SummaryTask[]         // 그날이 마감인 업무(완료된 것 포함)
}
SummaryPeriod {
  period: number               // 1~7
  start: string                // "HH:MM"
  end: string                  // "HH:MM"
  kind: "regular" | "substitute" | "cancelled"
  class?: SummaryClass         // regular/substitute의 수업 학급. cancelled면 원래 정규 학급(없을 수도 있음)
  replacedClass?: SummaryClass // substitute일 때 원래 정규 학급
  topic?: string               // 그날 기록된 차시 주제
}
SummaryClass { label: string /* "3-6" */; subject?: string /* "고전읽기" */; homeroom: boolean }
SummaryEvent {
  title: string
  scope: "school" | "personal" | "google"   // google 추가(2026-10-23): 설정에서 고른 구글 캘린더 일정(읽기 전용)
  category?: string            // 학사일정·교내행사 등(school일 때)
  allDay: boolean
  time?: string                // allDay=false일 때만 "HH:MM"
  location?: string
  startDate: string; endDate: string   // 여러 날 일정이면 둘이 다름
}
SummaryTask { title: string; priority: string /* 낮음|보통|높음|긴급 */; status: string /* 대기|진행중|보류|완료 */; dueDate: string }
```

### 3.4 시간과 신선도 규칙
- 기준 시간대는 **한국 표준시(Asia/Seoul)**. 위젯의 "오늘"·"지금"은 기기의 현재 시각을 쓴다.
- `days`에서 `date`가 오늘인 항목을 찾는다. 없으면 요약이 낡은 것이다 → 3종 카드 모두 "교사도우미를 열어 갱신해 주세요"를 보여 주고 마지막 갱신 시각을 표시한다.
- `generatedAt`이 3일 이상 지났으면 시간표 카드 머리글의 갱신 표시를 호박색으로 바꾼다(`N일 전 데이터`).
- 요약은 교사도우미에서 데이터를 고쳐 동기화가 올라갈 때만 새로 만들어진다. 14일 넘게 아무 변경이 없으면 위 "낡음" 상태가 된다(알려진 한계).

## 4. 위젯 3종: 표시 규칙

공통 스타일(2026-10-22 실기기 확인 후 조정): 어두운 둥근 카드(`#1b2128`, 테두리 `#2c353f`, 반지름 16dp), 본문 14sp, 보조 글씨 12sp·회색(`#8f9aa6`), 머리글은 작은 아이콘 + 제목(15sp) + 오른쪽 보조 정보. (최초 시안의 12/11/13sp는 실기기에서 너무 작아 한 단계씩 키움). 교시 번호는 원형 배지, 교체·휴강·D-day 태그는 배경 있는 칩으로 표시한다.
잠금화면·홈 화면 배경 위에 놓이므로 카드 자체가 불투명 배경을 가진다. (잠금화면 노출은 Good Lock LockStar 전제, §6 참고)

### 4.1 오늘 시간표 카드
- 머리글: 시계 아이콘 · "오늘 시간표" · 오른쪽 `HH:MM 갱신`(= `generatedAt`을 KST로).
- 상태 줄(녹색 `#5ee0b0`), `kind`가 regular/substitute인 교시만 대상:
  1. 지금 진행 중(`start <= 지금 < end`)인 교시가 있으면 `지금 N교시 · M분 남음`
  2. 없고 앞으로 시작할 교시가 있으면 `다음 N교시 HH:MM`
  3. 오늘 교시는 있었지만 모두 끝났으면 `오늘 수업이 모두 끝났어요`
  4. 오늘 `periods`가 비어 있으면 `오늘은 수업이 없어요`
- 줄(교시 하나당 두 줄): 왼쪽 원형 교시 번호(20dp) → 1행 `{subject} {label}`(담임 학급이고 subject가 없으면 `담임 {label}`) → 2행 `{start}` + 아래 보조.
  - regular: `{start} · {topic}`(topic 없으면 시각만)
  - substitute: `{start} · {replacedClass.label} → {class.label}` + 오른쪽 호박색 태그 `교체`
  - cancelled: 1행에 취소선·회색, 오른쪽 회색 태그 `휴강`. 상태 줄 계산에서 제외.
- 상태: 끝난 교시(`end <= 지금`)는 불투명도 45%. 진행 중인 교시는 줄 배경 `#143a2d` + 번호 원을 녹색(`#34d399`)으로.
- 수업 없는 교시는 표시하지 않는다(요약에 없음).
- ~~높이가 모자라면 끝난 교시부터 접고 `+N교시`로 줄인다.~~ → **변경(2026-10-23):** 일부 교시가 안 보인다는 피드백으로, 접어 숨기는 대신 `LazyColumn`으로 **위젯 안에서 스크롤**해 전체 교시를 볼 수 있게 바꿈.

### 4.2 오늘 일정 카드
- 머리글: 달력 아이콘 · "오늘 일정" · 오른쪽 `N건`.
- 오늘 날짜의 `events`를 **받은 순서 그대로** 쓴다(이미 시간 있는 일정 → 시간순, 종일은 뒤).
- 줄: 점(school=보라 `#a78bfa`, personal=장미 `#fb7185`) · 시각(`time` 또는 `종일`) · 제목 한 줄(넘치면 …).
- 시간이 지난 일정은 흐리게(45%) 표시한다(종일 일정은 제외).
- 높이가 모자라면 `+N건`.
- 일정이 없으면 `오늘 일정이 없어요`.

### 4.3 업무 카드
- 머리글: 체크리스트 아이콘 · "업무" · 오른쪽 `N건`.
- 대상 = `overdueTasks` + 모든 `days[].tasks` 중 `status != "완료"`. 중복(같은 제목·마감일)은 하나로.
- 정렬: 마감일 오름차순, 같으면 우선순위(긴급 > 높음 > 보통 > 낮음).
- 줄: 제목 한 줄 + 오른쪽 태그(마감 대비 오늘):
  - 지남: `N일 지남`(붉은 태그 `#4a1f26`/`#fb9aa8`)
  - 오늘: `D-DAY`(붉은 태그)
  - 앞으로: `D-N`(회색 태그)
- 업무가 없으면 `처리할 업무가 없어요`.

### 4.4' 주간 달력 카드 (4번째 위젯, 2026-10-23 추가)
- 사용자가 "업무·행사·일정" 화면의 달력을 위젯에서 보고 싶다고 요청. 위젯은 웹페이지를 못 띄우므로, 같은 데이터로 **오늘부터 7일**(요약이 과거 날짜를 안 주므로 일~토 고정 주가 아니라 "오늘부터 7일")짜리 요일 줄을 새로 그린다.
- 시간표(periods)는 포함하지 않는다 — "업무·행사·일정" 화면 자체가 그 둘만 다루는 화면이기 때문.
- **세로로 7일을 쌓는다**(처음엔 가로 7칸으로 만들었다가 사용자 요청으로 세로 목록으로 바꿈, 2026-10-23). 줄마다 왼쪽에 요일+날짜(오늘은 초록 원으로 강조), 오른쪽에 그날 일정·업무 **제목을 색 점과 함께 2개까지** 보여주고, 3개째부터는 `+N`으로 접는다. 항목 순서: 그날 일정(이미 시간순) → 그날 마감인 업무.
- 점 색: 학교일정 보라, 개인일정 장미, 업무 마감 빨강(§4.3과 동일 팔레트).
- 탭 동작은 일정·업무 카드와 동일(`/tasks`).
- 기본 크기는 세로로 긴 200×260dp(7줄 + 헤더가 들어가도록). 7줄을 넘는 높이가 필요하면 `LazyColumn`이라 위젯 안에서 스크롤된다.

### 4.4 개인정보 가림 옵션
위젯 앱 설정 화면에 **독립된 스위치 2개**(기본값 모두 꺼짐):
- `개인 일정 제목 가리기`: `scope == "personal"` 일정의 제목을 `개인 일정`으로.
- `업무 제목 가리기`: 업무 카드를 줄 대신 한 줄 `업무 N건`(마감 지난 건이 있으면 ` · M건 마감 지남`)으로.
- 학생 정보는 요약에 아예 없으므로 가림 대상이 아니다.

### 4.5 탭(터치) 동작
- 시간표 카드 → 교사도우미의 시간표 화면, 일정·업무 카드 → 업무·행사·일정 화면을 연다.
- 교사도우미(PWA)의 주소는 코드에 박지 말고 설정 화면의 입력 칸으로 받는다(경로: `/timetable`, `/tasks`). 비어 있으면 탭 동작 없음.
- 잠금 상태에서의 탭은 잠금 해제 후 실행되거나 무시될 수 있다 → 0단계에서 확인(LockStar 경유 시 동작 방식이 다를 수 있음).

### 5.1 화면
- **설정 화면(런처 아이콘으로 열림)** 한 장:
  1. 동기화 주소 입력 칸(붙여넣기) + "연결 확인" 버튼(`part=summary` 한 번 호출해 성공/실패 표시)
  2. 가림 옵션 스위치 2개
  3. 위젯 배경 색상(6자리 16진수 입력) + 배경 투명도 슬라이더(0~100%, 2026-10-22 추가 — 사용자가 직접 바꿀 수 있어야 한다는 요청으로 넣음)
  4. 교사도우미 열기 주소 입력 칸
  5. 마지막 갱신 시각, "지금 새로고침" 버튼, 마지막 오류 메시지
- 위젯 3종은 홈/잠금화면의 위젯 목록에서 추가한다.

### 5.2 갱신 방식
- WorkManager가 15분마다 요약을 받아 저장하고 3종 위젯을 다시 그린다.
- **교시 경계 갱신**: "지금 교시" 강조와 "남은 분"이 맞으려면 시각에 맞춰 다시 그려야 한다. 오늘 요약의 각 교시 `start`/`end`와 일정 `time`에 맞춰 다음 경계 시각에 알람(`setAndAllowWhileIdle`, 정확 알람 권한 없이)을 걸어 다시 그린다. 몇 분 늦을 수 있음 → 0단계에서 체감 지연을 측정.
- "남은 분"처럼 분 단위로 계속 변하는 값은 정확히 맞추려 애쓰지 않는다(경계 시점마다 갱신하면 충분).
- 실패 시: 마지막 성공 데이터를 그대로 보여 주고 갱신 시각만 낡게 둔다(빈 화면 금지). 설정 화면에 오류를 남긴다.

### 5.3 보안
- 동기화 주소(키 포함)는 앱 전용 저장소에만 둔다(다른 앱 접근 불가). 가능하면 Android Keystore로 암호화.
- 로그·크래시 리포트에 주소를 남기지 않는다. 코드·저장소에 키를 넣지 않는다.
- 네트워크는 HTTPS만.

## 6. 진행 순서와 검증

### 0단계: 시험용 위젯 (본 개발 전 필수)
최소 앱을 만들어 탭에 설치하고 아래를 확인한다. **통과해야 1단계로 간다.**

**→ 0단계 전 항목 통과(2026-10-22). 1단계로 진행 가능.**

| # | 확인 | 통과 기준 | 결과(2026-10-22) |
|---|---|---|---|
| 1 | 잠금화면 위젯 목록에 앱의 위젯이 나타나는가 | 잠금화면 편집에서 추가 가능 | **조건부 통과** — 기본 OS 잠금화면 "위젯 추가" 목록은 삼성·구글 1st-party 앱으로 고정되어 3rd-party 위젯이 안 뜸. **Good Lock의 LockStar 모듈을 켜면** 목록에 뜨고 추가·정상 동작함. → 최종 사용자 안내에 "Good Lock + LockStar 설치" 전제조건 추가 필요 |

| 3 | 위젯을 몇 개까지 놓을 수 있는가 | 3개 동시 배치 가능 여부와 크기 | **통과** — 3개 동시 배치 확인 |
| 4 | 크기 조절·배치가 되는가 | 세로·가로 화면 확인 | **통과(원인 규명 완료)** — LockStar는 가로·세로 배치를 **따로** 저장한다. 가로에서 추가한 뒤 기기를 돌리면 세로용 배치가 없어서 사라지는 것처럼 보였을 뿐, **세로 상태에서 처음부터 다시 추가하면 정상 표시됨**(확인 완료). 버그 아님 — 안내문에 "가로·세로 둘 다 쓰려면 각 방향에서 한 번씩 추가해야 함"을 적어 둘 것 |

| 7 | 15분 주기 갱신·경계 알람 | 실제 지연 측정 | **통과** — 실기기에서 15분 주기로 "갱신:" 시각이 정상적으로 바뀜 확인 |

0단계에서 막히면 대안: (a) 홈 화면 위젯으로 제공, (b) 요약 이미지를 만들어 잠금화면 배경으로 쓰는 방식(하루 단위 갱신) — **둘 다 불필요**: Good Lock(LockStar)로 잠금화면 노출 자체가 됨이 확인됨. 단 LockStar 비활성 사용자는 홈 화면에서만 보임.

### 1~3단계
1. 요약 파싱과 카드별 표시 규칙을 **순수 Kotlin 함수**로 만들고, §3.3 예시 JSON으로 단위 테스트한다(시각을 바꿔 상태 줄·강조·정렬·가림을 검증). 기기 없이도 검증 가능.
2. 위젯 3종 UI 연결 → 설정 화면 → 갱신 작업.
3. 마무리: 낡은 데이터 표시, 오류 안내, 어두운 배경 대비 확인, 서명한 릴리스 APK.

### 빌드와 설치
- 집 PC에 Android Studio(최신)와 SDK 36 필요. 탭은 개발자 옵션에서 USB 또는 무선 디버깅을 켜고 `adb install -r`로 설치.
- 서명 키스토어는 한 번 만들어 안전한 곳에 보관한다(저장소에 올리지 않는다). 같은 키로 서명해야 덮어쓰기 업데이트가 된다.
  - **완료(2026-10-23):** `C:\Users\ADMIN\keystores\teacher-widget-release.jks`(저장소 밖, 비밀번호는 같은 폴더의 텍스트 파일). `teacher-widget/keystore.properties`(git에는 안 올라감)가 `app/build.gradle.kts`의 `signingConfigs.release`에 연결되어 있어 `./gradlew assembleRelease`만 돌리면 서명된 APK가 나온다.
